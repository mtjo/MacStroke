## MacStroke 3.1.8

**新增 / Added**

- The "Screenshot / Recording" page carries a second shortcut row — Extract text, ⌥⇧A by default and rebindable. It opens the same overlay, already sitting on the Extract text mode: frame some text, release, and it is recognised and copied, with no stop at the annotation bar in between (issue #74)

  偏好设置「截图/录屏」的触发方式里多了一行「提取文字快捷键」，默认 ⌥⇧A、可以改键。按下去开的是同一个遮罩，但一开出来就亮在「提取文字」那一档：框住文字松手就识别并复制，中间不停在注解条上（issue #74）

- Same as the screenshot row, its recorder has a clear button on the right — emptying it unbinds the shortcut

  和截图那行一样，框的右边有清除按钮，置空就是不挂这条快捷键

**注意 / Notes**

- A matched press is swallowed rather than handed to the frontmost app, so ⌥⇧A does not also type an "Å" wherever the focus is. Extraction needs the same Screen Recording permission the screenshot already asks for

  命中即吞，不会顺带给前台打出一个 Å 字符；提取文字要的是和截图同一条「屏幕录制」权限

- Don't bind the two rows to the same combination: both listeners fire, so the overlay opens and cancels itself in the same beat. And while a recording or a long shot is running, this key closes that session — exactly like the screenshot key — instead of starting an extraction

  两行别改成同一个组合：两只监听都会命中，遮罩会刚开出就被自己取消。录屏或长截图进行中按这一条，是给那一场收尾出片（和截图键一致），不是去开提取文字
