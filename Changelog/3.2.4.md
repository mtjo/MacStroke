## MacStroke 3.2.4

**新增 / New**

- Mouse wheel up / down can now trigger gestures as rules: pick "wheel up" / "wheel down" in the gesture column of a rule — no drawing needed, the moment you scroll the wheel the matched action fires (issue #78). The old wheel page is gone: existing wheel settings migrate into rules automatically on first launch, one direction one rule, and the rules file is not touched if there's nothing to migrate. Middle / side buttons (back / forward) get the same treatment: they can start an instant gesture, and if a button is both your gesture-start button and a rule trigger, the start button wins — the rule waits, and you get a notification plus a standing orange hint on the General page explaining the precedence.

  滚轮上 / 下现在可以当作规则的手势来触发：规则页手势列直接选「上滚 / 下滚」，不用画轨迹，滚一下 matched 的动作就执行（issue #78）。旧的滚轮设置页撤了：老设置首次启动自动迁成规则，一个方向一条，没有可迁的就不动 rules.json。中键 / 侧键（后退 / 前进）同一待遇：都能做起手即触发的瞬时手势；若某个键既是手势起始键又是规则触发键，起始键优先、规则让路，并弹通知 + 常规页常驻一行橙色提示讲清这个优先级。

- Volume up / down / mute are now action choices in a rule, alongside key press and AppleScript (issue #78). One trigger fires one step.

  音量 +1 档 / -1 档 / 静音进了规则动作下拉，与按键、AppleScript 并列（issue #78）。一次触发推一档。

- Double-click any shortcut recorder to open an on-screen keyboard — click the modifiers you want (they toggle, multiple allowed), then click the main key to commit; a modifiers-only recorder shows just the five modifier keys and a Done button (issue #78). The keyboard is drawn after Apple's compact Magic Keyboard; keys not on it (F13 and up, most keypad keys) are still reachable via "Type instead…" at the panel's lower-left corner, the old text entry with its three kinds of rejection feedback. While recording, the box now only shows a short "录制中…" (or the held modifiers as symbols) — the full instruction lives in a bubble above the box, and it tells you double-click opens the keyboard, the only visible hint of that entry.

  双击任意快捷键录制框弹出屏幕键盘 —— 先点修饰键（可切换、可多选），再点主键提交；修饰键模式的框只摆五个修饰键和「完成」（issue #78）。键盘照不带小键盘的妙控键盘画；表里没有的键（F13 以上、多数小键盘键）走面板左下角「改成手写…」，即原来的文本填法，三种拒法反馈照旧。录制中框里只显示短句「录制中…」（按住修饰键时显示 ⌃⇧… 符号），完整提示挪到框上方的气泡里，并写明双击打开键盘 —— 这是那个入口唯一看得见的提示。

**修复 / Fixed**

- After a screenshot was taken, the main app could jump to the foreground on its own. The snapshot focus bookkeeping now runs in the right order and hands focus back properly (issue #78).

  截一张图后主程序可能自己跳到前台。截图焦点的记账次序修正，用完即归还（issue #78）。

**其余 / Also in this version**

- Preferences sidebar regrouped into 手势 / 扩展 / 应用 sections; a "Restore Defaults" with confirmation and per-page undo landed on General and Rules; the rules table adapts to narrow windows; hint bubbles got a layout pass; toolbar icons and help texts were aligned with the rest of the app. Full accounting and the acceptance checklist live in `docs/wheel-gesture-issue78.md` (Chinese).

  偏好侧栏重排为手势 / 扩展 / 应用三组；常规页与规则页新增「恢复默认设置」（带确认框与页面内撤销）；规则表适配窄窗口；提示气泡做了一轮排版；图标按钮与帮助提示统一。完整账目与验收清单见 `docs/wheel-gesture-issue78.md`（中文）。
