## MacStroke 3.1.9

**新增 / Added**

- Annotations can be edited after they are drawn: eight handles resize the shape, pressing its line drags the whole thing, Delete removes just that one, and the stroke you just finished comes pre-selected. No more disarming the tool first — pressing a shape selects it, wherever the tool bar sits (issue #73)

  画上去的箭头、方框、字都能回头改：八颗把手改大小，按住它自己整条挪，Delete 删掉选中的这一条。进编辑不用再摘掉工具——按在哪一条上就是改哪一条，刚画完那一笔本身也是选中态（issue #73）

- The five colour chips and three width chips on the bar are now a property panel that sits above whichever tool you picked: seven preset colours plus a custom one, and each tool keeps its own set — a thick arrow and a thin box no longer mean re-tuning between strokes

  条子上原来那 5 色 + 3 粗细收进一块属性面板，钉在你选中的那一格上方：七档预设色加一枚自定义取色，每格工具各记自己那套粗细和颜色。箭头要粗、框要细，不用每画一笔重调一遍

- Text gets its own controls: a size slider, bold, italic, border and background — line width is no longer the only way to make a label bigger (issue #73)

  文字那一格有自己的滑杆：字号、粗体、斜体、边框、底衬。以前只能拿线条粗细当字号使，现在直接调（issue #73 的 2.3）

- Double-click a label you already wrote to put the caret back into it; the field lands on the old text and only the words change — position, size and style stay where they were

  双击已经写好的那行字，输入框直接盖回原字上；改的只有文字，位置、字号、底衬一个都不动

- General page gains one switch: don't pop the right-click menu when a drawn gesture matches nothing (issue #73, and the follow-up in #68)

  常规页多一个开关：手势画完没匹配上任何规则时，不再弹出右键菜单（issue #73 的第 1 条，#68 里也追问过）

**注意 / Notes**

- That switch is off by default, which is the original behaviour: a misdrawn stroke still hands the click back so the menu comes up. Turning it on only affects gestures you actually drew — a plain right-click still opens the menu, and it takes effect immediately without a restart

  开关默认关，也就是原版行为：画错了还把这次点击交回应用，菜单照常弹。勾上以后也只认「真的画了一条」，纯右键单击不受影响；勾上立刻生效，不用重启

- The panel edits the annotation that is currently selected. To change what the *next* stroke looks like, click the tool cell first (that drops the selection) and tune it there. Mosaic takes neither colour nor width, so it never opens the panel

  面板改的是「当前选中的那一条」。想让**下一笔**用新值，先点工具格子（那一下会掉选中）再调。打码那一格不吃色也不吃粗细，所以它压根不弹面板

- Each tool's colour and width live only inside this screenshot session: closing the overlay resets everything to red at the default width. Nothing is written to preferences

  每格工具那套粗细颜色只在这次截图里有效：这次会话一关就全部回到「红 + 默认粗细」，不写进偏好设置
