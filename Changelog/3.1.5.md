## MacStroke 3.1.5

**修复 / Fixed**

- The update window shows the changelog again: `releaseNotesLink` was written across several indented lines in the update feed, and Sparkle hands that element's text straight to `NSURL`, which reads the leading newline and returns nothing — so the notes pane stayed empty and the log was only ever on the release page (issue #71)

  更新提示弹窗重新显示更新日志：更新源里的 `releaseNotesLink` 是跨行缩进写的，Sparkle 把这个元素的文本直接交给 `NSURL` 解析，开头那个换行让解析结果是「没有链接」，日志区于是始终是空的，想知道改了什么只能自己去 release 页面翻（issue #71）

**新增 / Added**

- Each version's notes are published as real Markdown (`Changelog/<ver>.md`): the update window lays them out as a heading plus a list instead of raw `+` / `!` marker lines, and the GitHub release body is built from the same file

  每版的更新说明改用真正的 Markdown 发布（`Changelog/<ver>.md`）：更新窗里排成「版本标题 + 列表」，不再是 `+` / `!` 标记的原始行；GitHub release 的正文也由这同一份文件生成

**注意 / Notes**

- Entries already in the feed keep the previous formatting, so only this version onward shows notes in the update window

  更新源里已经发出去的条目仍是旧写法，所以只有从这一版起，更新窗才有日志
