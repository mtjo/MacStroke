## MacStroke 3.2.0

**新增 / Added**

- Selecting text now pops a capsule above the pointer with four cells: copy, search, translate, read aloud. It has its own page in Preferences, with a master switch and a switch per cell. Off by default.

  划词气泡：选中一段字后，指针上方弹一枚胶囊，四格分别是复制、搜索、翻译、朗读。偏好设置里是独立一页，带总开关，四格各自也能单独关掉。默认关闭。

- Two ways to call it: drag with the left button and release (the read happens 250 ms later by default, adjustable), or press a shortcut — ⌃⌘B out of the box, rebindable — to take whatever the focused field has selected. Keyboard selection (the ⌥⇧→ kind) produces no mouse events, so the shortcut is the only route that works there. Neither route touches gesture capture: the left-button monitor is read-only, so recognition and latency are exactly as before.

  两条触发：左键划完松手自动弹出（松手后默认等 250 毫秒再读，可调），或按一下快捷键 ⌃⌘B（可改键）把当前焦点上选中的字叫出来。键盘选字不产生鼠标事件，只有第二条路叫得出气泡。两条都不碰手势捕获层：左键监听只读不吞，识别和耗时与这一版之前一模一样。

- Chrome, Messages and Electron apps get their accessibility interface switched on when needed, and the selection is looked for in several places (the focused element, its containers, the element under the pointer), so editors that only report it on a parent or a child cell still work.

  Chrome、信息、Electron 那一类软件需要时会被当场打开无障碍接口，读选区也按几种读法依次试：焦点元素、往上找容器、按鼠标点命中的那一格 —— 所以只在父格或子格上报选区的编辑器照样读得到。

- For apps with no accessibility exit for their selection at all — Mail's message body is exactly that — the bubble can press ⌘C for you: your clipboard is saved first, put back as soon as the text is read, and those few writes are not recorded in MacStroke's own clipboard history. It only runs when every read above came up empty; a read timeout never triggers it.

  正文压根没有无障碍出口的那类软件 —— 邮件就是 —— 可以替我按一次 ⌘C 取字：动手前先把粘贴板原样存下，读到字立刻放回，前后不到一秒，这几笔也不进 MacStroke 自己的粘贴板历史。它只在上面几种读法全都拿不到字时才上场，读取超时不会触发它。

- Where the search cell goes is now a setting: six search engines (Google, Bing, DuckDuckGo, Baidu, Sogou, 360), eight web AI pages (ChatGPT, Copilot, Perplexity, Gemini, DeepSeek, Doubao, Kimi, Tongyi), plus a custom URL template of your own.

  「搜索」那一格走哪家现在是设置项：搜索引擎六家（Google、必应、DuckDuckGo、百度、搜狗、360）、网页 AI 八家（ChatGPT、Copilot、Perplexity、Gemini、DeepSeek、豆包、Kimi、通义），再加一条自定义 URL 模板。

- One more switch, off by default: for a page that cannot take the query in its URL, after it opens wait 1.2 seconds and press ⌘V once for you, so the words land in the AI's input box.

  再多一颗开关，默认关：那些「网址带不进关键词」的页面打开后等 1.2 秒，替你把刚复制的那句按一次 ⌘V 送进输入框。

**注意 / Notes**

- Nothing happens until you turn it on in Preferences → Selection Bubble, and turning it off removes the listeners at the root: no left-button monitor is installed and the shortcut is not registered, rather than listening and discarding the result. Reading selections needs the Accessibility permission MacStroke already asks for at launch — no additional permission. Which apps are skipped still follows the black/white list on the Filter page; this page does not keep a second list.

  整条功能默认关，要在偏好设置 → 划词气泡里勾上才生效；关掉是关到根上 —— 那三样左键的全局只读监听整个不挂、快捷键给空串，而不是挂着监听什么都不弹。读选中文字要的是启动时已经要求过的「辅助功能」授权，不多要权限。哪些软件不弹沿用「过滤」页那套黑白名单，这一页不再配第二份名单。

- A single rule decides what a search destination does: a template containing {query} gets the selection URL-encoded into it; a template without it only opens the page, after putting the selection on your clipboard. The eight AI pages copy even when their template does carry the placeholder, because their prefill is undocumented and comes and goes; the six engines never touch your clipboard. An empty or unrecognisable custom template falls back to the default engine rather than opening nothing.

  一条规则决定这一家怎么动作：模板里有 `{query}` 就把选中的字拼进网址；没有就只打开那一页，并先把那段字放进粘贴板等你 ⌘V。网页 AI 那八家即使模板带了占位符也照抄一次（那几家的预填官方没文档、时灵时不灵）；搜索引擎那六家绝不碰你的粘贴板。自定义那一栏空着或不像网址时，点的仍是默认那一家，而不是什么都不开。

- Auto-paste is off by default because it targets whichever window is frontmost when the timer expires: if the page hasn't put its caret into the input box yet, that ⌘V lands in the address bar. Two checks run before the keystroke — the clipboard no longer holds what we just wrote, or the front window is MacStroke's own — and either one makes it do nothing. Engines that can take the query in the URL never get the extra keypress, even with the switch on.

  「自动贴」默认关，是因为它投的是**等的时候前台那个窗口**：网页还没把光标落进输入框时，那一下会打进地址栏。真投之前还要核两句 —— 粘贴板里已经不是刚才那句、前台已经换成我们自己的窗口，任一命中就什么都不做。真能把字拼进网址的那六家，开关开着也不会多按一次键。

- Don't bind the bubble's shortcut to a bare ⌘C or ⌘V: our own synthetic press would be heard back as a new trigger and start cycling. When the shortcut is set that way the page says so in orange and that fallback simply doesn't run; adding one more modifier is enough. Read aloud uses the system synthesiser — nothing installed, no network, no key — and mixed Chinese/English wording is not accurate yet.

  别把气泡快捷键录成单纯的 ⌘C 或 ⌘V：我们自己投出去的那一下会被重新监听成一次唤出。录成那样时页面会出现橙色那句话，并且这一手压根不上场 —— 再加一个修饰键就能用。朗读用的是系统自带的合成器，不装东西、不要网络、不要密钥，中英混排念得不准，一期就是这样。
